# superSearchPlus-Tools
这是一款聚合型信息收集插件，支持综合查询，资产测绘查询，信息收集 敏感信息提取、js资源扫描、目录扫描、vue组件扫描，整合了目前常见的资产测绘平台，目前已有工具版和插件版，都可以进行下载使用。
